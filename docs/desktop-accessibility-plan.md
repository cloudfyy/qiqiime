# 桌面显示与易读模式改造方案

本方案已获准实施。共享显示配置、设置窗口和自绘候选窗已接入；
具体使用范围与限制见[显示与易读指南](accessibility.md)。
下文保留设计与验收约定；构建、lint、覆盖率的实际结果以发布验证记录为准，
不能仅凭方案宣称已完成真实宿主或读屏验收。

## 1. 本批范围

- 建立共用的显示偏好、有效主题与布局度量。
- 改造设置窗口，提供主题、字号、易读模式和预览。
- 改造输入法自绘候选窗，支持相同偏好及可靠的放大布局。
- 词库管理器和 Log Monitor 下一批接入，不在本批重排其界面。
- 不改变 Windows 设置，不改变输入算法、候选顺序、默认分页或快捷键。
- 网站偏好仍只存在浏览器内，不与桌面配置互相覆盖。

## 2. 默认行为与操作约定

| 项目 | 建议行为 |
|---|---|
| 主题 | 跟随系统、明亮、深色、高对比度 |
| 默认主题 | 跟随系统，保留桌面端目前行为；不同于网站默认明亮 |
| 字号 | 100%、125%、150%、200%，默认 100% |
| 关怀模式（Comfort mode） | 默认关闭；开启时将小于 150% 的字号提高到 150% |
| 单独调整字号 | 关怀模式开启时只能选 150%/200%；关闭后保留字号并恢复全部选项 |
| 系统高对比度 | 始终优先，使用 Windows 系统颜色，不覆盖用户的系统配色 |
| 手选高对比度 | 系统未启用高对比度时，使用应用自有的高对比调色板 |
| 恢复默认设置 | 统一重置显示选项、词库、输入习惯和语言等设置，不另设显示重置按钮 |

易读模式提供更宽松的间距、更大的点击区域、更清楚的选中状态，
减少装饰；不通过隐藏功能实现“简化”。
系统要求减少动画时始终遵守，不新增无必要的动画。

## 3. 共用配置与显示层

### 配置复用

在现有 `QiQiConfig` 和 `kConfigFields` 中增加三个设置可编辑字段：

- `ui_theme`：类型安全的四选一枚举。
- `ui_text_scale`：四档枚举，映射到实际比例，避免接受 126% 等未支持值。
- `easy_reading`：布尔值。

继续复用注册表持久化、设置三方合并、备份及配置版本通知；
不另建配置文件，不新增轮询线程，不把测试主题 override 用作生产配置。
旧配置缺少字段时保持当前默认行为；验证非法值、旧备份及新旧字段的兼容处理。

### 有效外观解析

一个共享解析入口接收“偏好 + 系统状态”，输出有效调色板与度量：

1. Windows 高对比度开启：系统颜色优先。
2. 否则按应用主题选择，跟随系统时读取 Windows 应用明暗设置。
3. 统一输出正文、次要文字、背景、选中、悬停、边框、焦点和禁用态颜色。
4. DPI 与用户字号分别参与计算且只转换一次；字号、内边距、命中区域
   使用各自的度量，不把系统 DPI 全局伪装成 150%。

字体及画刷沿用现有 RAII 包装；变更后统一失效并重建必要资源，
绘制、测量与命中测试使用同一份有效外观。
避免每次绘制都读取注册表。

### 同步与宿主边界

- 保存成功后复用现有配置通知；在各窗口所属线程刷新外观和布局。
- 系统主题、高对比度或 DPI 变化时重新解析，不回写用户偏好。
- 设置编辑期间继续按现有 baseline/local/external 规则合并，
  不用整份旧配置覆盖其他进程刚保存的输入选项。
- 输入法 DLL 位于宿主进程内：不得为了候选窗主题调用会修改
  **整个进程** 首选主题模式的接口，避免改变宿主菜单或其他窗口。
- 本批保证设置窗口和自绘候选窗同步；不能宣称尚未接入的工具已经支持。

## 4. 设置窗口

设置改为五个分类 Tab，避免配置增加后挤在同一页：
输入习惯、词库、候选窗口、显示与易读、声音与反馈。
复用现有控件绑定与配置读写，不为每页维护重复配置。

- Tab 栏复用共享主题调色板，覆盖背景、文字、选中态、键盘焦点和翻页箭头。
  采用原生 Tab 的选择/可访问名称；大字号时横向翻页，避免多行页签挤占内容区。
- 页签栏和底部“确定/取消”固定，只有当前页可纵向滚动。
- 切换页保留未保存编辑和各页滚动位置；Ctrl+Tab / Ctrl+Shift+Tab 切换分类。
- 常规字号采用标签/控件横排，小屏、大字号或易读模式上下排列。
- 焦点进入屏外控件时自动滚动到可见区域。
- 标签支持中英文换行；布局使用下拉框实际折叠高度，避免与后续控件重叠。
- 对页面控件和候选预览执行绘制裁剪，不能遮盖页签或底部按钮。
- 易读模式下主要操作和可点击选项目标至少 44×44 DIP；
  复选框整行文字也可点击。

“显示与易读”页提供：

```text
主题          [跟随系统       v]
文字大小      [100%           v]
[ ] 关怀模式 / Comfort mode
候选窗预览    编码、候选、选中框、上一页 / 下一页
```

选择后只在设置窗口及其嵌入预览中即时生效，不立即全局保存。
“确定”成功保存后才更新真实候选窗；“取消”丢弃预览修改。
保存失败保留编辑并明确提示，不显示成功状态。
系统高对比度生效时显示原因说明，保留用户原有主题选择以便系统模式退出后恢复。

保留现有全量“恢复默认设置”的语义，另设仅显示重置，避免误改输入习惯。
继续使用有明确标签的原生交互控件，检查 Tab/Shift+Tab、方向键、
空格、Enter、Esc 和高可见焦点；不能只验证鼠标操作。

## 5. 候选窗

### 绘制与交互

- DirectWrite/Direct2D 与 GDI 回退共用颜色、字号、测量规则及命中区域。
- 字号、DPI 或易读模式变化均触发布局重算，不能只按 DPI 判断字体缓存有效。
- 选中候选增加背景或边框提示，不能仅靠文字颜色区分。
- 易读模式显示“上一页 / 下一页”等文字标签；主要命中区域至少 44×44 DIP。
- 保持不激活窗口，不抢宿主焦点，保留数字选词和现有翻页行为。
- 只更新展示，不借主题切换清空组合、修改选中项或启动新的编辑会话。

### 屏幕边界与长文本

复用现有文本测量和工作区定位，在计算尺寸前约束可用空间：

1. 按当前显示器工作区、DPI 和实际字体测量。
2. 横排过宽时按候选项换行，保留候选顺序与编号，不暗改用户横/竖排配置。
3. 单条过长时支持内容换行，不将隐藏候选或静默缩小字号作为解决办法。
4. 靠近屏幕底部时向上放置，并重新检查上下左右边界。
5. 极小工作区连完整一页都无法容纳时，采用页内可滚动视口，
   选中项自动滚入；不改变引擎页大小，所有候选必须仍可到达。
   该退化路径单独实现和测试，不仅调用位置 clamp 后任由内容越界。

TSF 无界面模式中，候选内容和分页仍通过既有接口交给宿主，
本软件不能保证或强制宿主自行绘制的候选界面使用这些颜色与字号。

## 6. 验收与测试

| 类别 | 必须验证 |
|---|---|
| 默认兼容 | 无新字段时保持系统跟随、100%、原输入行为 |
| 配置 | 四档值校验、保存/重载、备份兼容、显示单独重置、并发合并 |
| 主题 | 四主题；系统明暗及高对比度进入/退出；不改变宿主进程主题 |
| 视觉指标 | 应用高对比度正文、次要文字及选中文字与背景至少 7:1；系统配色使用系统值 |
| 放大与重排 | 100/125/150/200% × 96/144/192 DPI；中英文、长路径、窄屏 |
| 操作目标 | 易读主要按钮与候选翻页区域至少 44×44 DIP，检查实际尺寸 |
| 设置交互 | 完整键盘操作、滚动跟随焦点、预览取消、保存失败保留编辑 |
| 候选展示 | 横/竖排、1～9 项、长候选、多页、工作区四角、跨 DPI 显示器 |
| 输入安全 | 改主题不失焦、不清组合、不改排序；无界面模式接口行为不变 |
| 绘制回退 | D2D 与强制 GDI 回退均可读、命中位置一致 |

优先扩展现有配置、设置窗口和候选窗测试，补少量纯布局计算测试；
不引入新的 UI 框架。自动化后用真实 Windows 高对比度、
跨显示器和放大镜进行人工验收，检查控件可访问名称与状态。
本批不等同于完整读屏认证；若发现缺失的候选可访问性接口，
应单列范围和验收，不能仅凭可视放大宣称全面支持读屏。

原生改动完成后做 RAII、复用、C++ Core Guidelines/GSL 和遗漏测试检查，
运行 x64/x86 受影响构建与测试，不自动制作 MSI。
错误保留实际 HRESULT/Win32 错误码，诊断不记录输入文本或其他敏感内容。

## 7. 建议实施顺序

1. 共用配置、主题解析和布局度量，先补纯逻辑与兼容测试。
2. 设置窗口重排、显示选项及本地预览。
3. 候选窗双绘制路径、放大布局与屏幕边界处理。
4. 两者联调、x64/x86 验证及人工无障碍验收。
5. 再将同一显示层接入词库管理器与 Log Monitor，避免各写一套。
