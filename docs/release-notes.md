# QiQiIME 1.0.4 补丁版

数字版本：`1.0.4`；Git 标签：`v1.0.4`。

## 本次主要更新

- 新增 Windows 10 22H2（x86 / x64）支持目标，明确 Windows 10 API 编译基线；原生 32 位系统只检查和注册 x86 组件，不再强制要求 x64 文件。
- 注册脚本根据操作系统与 PowerShell 进程位数选择正确的注册工具，显式使用对应注册表视图，并核对注册后的 DLL 路径。
- 同一 WiX 源码生成 x64/x86 各自的中英文 MSI。x64 MSI 改名为 `win-x64-*.msi`，仍包含 WOW64 组件；新增 `win-x86-*.msi` 仅用于 32 位系统。
- x64 安装器保留原升级标识与组件身份；x86 使用独立升级标识、32 位目录和工具快捷方式，阻止在 64 位系统上误装。显式打包自动检查四个 MSI 的实际安装数据库。

## 升级注意事项

- 64 位 Windows 10/11 选择 x64 MSI，不需要另外安装 x86 MSI；32 位 Windows 10 22H2 选择 x86 MSI。安装包按系统位数选择，不按某个应用的位数选择。
- 旧 `win-x64-x86-*.msi` 属于 x64 升级系列；新 x64 文件名不改变升级身份。运行组件 ZIP 与符号 ZIP 仍使用 `win-x64-x86` 名称。
- 从 `1.0.3` 或更早版本升级前仍建议导出 `.qbak`、备份用户数据并关闭宿主，升级后重新打开应用并确认实际加载新版组件。词库、配置和调频迁移规则不变。

## 本次验证与发布边界

- 版本号更新前，x86/x64 Release 全量构建成功；x86 完整 CTest 为 **17 通过、2 项 ETW 集成因权限不足跳过**，x64 公共模块、引擎、TSF、设置、独立工具及架构脚本 **6 项定向回归通过**。
- 架构脚本在 Windows PowerShell 5.1、PowerShell 7 与真实 32 位 PowerShell 下通过；两架构安装器相关 CTest 各 **2/2 通过**。
- 升级版本号后，x64/x86 八个运行组件及公共/设置测试构建成功，八个 PE 数字文件版本均为 `1.0.4.0`；版本、设置、独立工具启动及安装器相关定向 CTest 共 **10/10 通过**。本地产物仍带提交前的构建身份，不作为标签附件发布。
- 使用真实构建产物在临时目录生成四个 MSI，并在 PowerShell 5.1/7 下核对包平台、文件集合、组件位数、升级身份、快捷方式和注册顺序；临时验证包不作为正式发布附件。
- 上述本地验证来自 Windows 11 x64 开发机，不替代 Windows 10 22H2 x86/x64 的真实安装、升级、输入及卸载验收。未在共享开发环境执行安装或修改本机输入法注册。

## 1.0.0 正式版历史记录

数字版本：`1.0.0`；Git 标签：`1.0.0`（不带 `v`）。

## 主要更新

- 发布面向 Windows 11 x64 的五笔 86 TSF 输入法，包含 x64 和 x86（WOW64 应用）组件。
- 提供中英文 MSI、双架构运行组件 ZIP，以及同次构建的独立 PDB 符号 ZIP。
- 包含 R01–R06 重构、组合生命周期与激活重入处理、统一禁输入准入、独立设置/词典管理/日志监控工具及 Metrics 视图。
- 用户词库文件作为唯一权威来源：桌面端复用只读同步通道，注册表 `UserDictSyncDirectory` 只发布绝对目录地址；AppContainer 读取快照和增量，不再使用注册表词库镜像。
- 二进制词组排序文件改用 `.qfreq` 后缀；缺失或不可读的共享快照不再被当成空词库成功加载。
- 合并重复清理和初始化逻辑，补充共享读取失败与路径容量边界测试，修复 C++ Core Guidelines/GSL 静态检查发现的告警。

## 升级注意事项

1. 升级前使用旧版词典管理器导出 `.qbak`，并另外保留用户词库、调频文件与配置备份；关闭正在使用输入法的应用。
2. 默认排序文件由 `phrase_freq.txt` 改为 `phrase_freq.qfreq`，同步目录相应改为 `phrase_freq.qfreq.sync`。旧文件和目录不会自动读取、迁移或删除，因此旧排序不会自动恢复；可先用旧版导出备份，再在新版词典管理器恢复调频数据。
3. 注册表 `UserDictQdict` 旧值保留但不再读取或写入，不自动迁移仅存于镜像中的词条。升级前确认个人词条已经保存到用户词库文件或已导出备份。
4. AppContainer 的共享地址需要桌面 IME 或使用配置路径的词典管理器成功生成并发布。只有明确发布空地址才表示没有用户词库；配置、路径或快照不可读时记录实际失败，不回退到旧镜像。
5. 同步目录给应用包授予只读权限，而非仅给 IME 授权；其他符合访问条件的应用包也可能读到个人词条。父路径、ACL 和宿主令牌仍会影响访问结果。
