# QiQiIME 1.0.9 补丁版

数字版本：`1.0.9`；发行标签：`v1.0.9`。标签推送后由 Release 工作流构建、测试和打包；实际附件以对应 Release 页面为准。

## 本次主要更新

- **普通日志统一使用 ETW**：移除普通调试器日志输出及 `LogLevel` 配置，采集详细程度由 ETW 会话的级别和类别决定。旧注册表 `LogLevel` 和备份中的 `log_level` 不再生效，无需手工删除；不再导出该配置。
- **保持 Metrics 独立**：指标仍须单独订阅，协议和行为不变。日志及指标基础设施自身失败时，保留非递归的应急调试诊断。
- **明确组合生命周期契约**：补充章节目录，并解释组合创建、停用与异步清理、立即重新激活、宿主提前终止、候选 UI 注册撤销、布局定位及上下文切换的背景、顺序和重入边界。
- **完善诊断与测试隔离**：日志测试复用私有 ETW 采集，覆盖级别/类别过滤、延迟启用、模块生命周期、旧配置兼容及重入格式化。布局回退用例显式建立无插入符条件，并记录焦点及插入符状态，避免依赖进入测试前的 GUI 状态。

## 验证与发布边界

- 日志变更后的 x64 Release 完整构建及 x86 公共库构建无警告。x64 定向回归的 11 项可运行测试通过，最初因权限跳过的两项全局 ETW 集成随后由用户在具备权限的终端执行通过。
- 用户执行 x86 普通回归时，16 项通过，TSF/UI 用例因进入布局测试前已有原生插入符而失败。显式初始化插入符状态后，用户重跑该项通过；两项全局 ETW 集成也由用户执行通过，x86 的 19 项均已有通过记录，并非同一轮全量通过。
- 版本号升级后，x64/x86 输入法与三个工具重新构建无警告，八个运行组件的数字文件/产品版本均为 `1.0.9.0`；x64 公共、TSF/UI、安装器与架构脚本回归 **4/4 通过**，x86 公共、安装器与架构脚本回归 **3/3 通过**。这也补齐了插入符准备修复后的 x64 TSF/UI 验证；本地构建的提交号来自发布提交之前，不是标签构建身份。
- 上述定向和历史回归不替代标签提交的双架构完整构建、测试，也不代表真实宿主、安装或升级已验收。
- 本机不制作或安装 MSI，不修改已安装输入法注册。发布工作流会生成 MSI、ZIP 和匹配符号；其成功状态和实际附件以 [v1.0.9 Release](https://github.com/cloudfyy/qiqiime/releases/tag/v1.0.9) 为准。推送标签不等于附件已经发布，二进制与 PDB 必须来自同一次构建。

- ZIP 的 `-RemoveUserData` 不会再次询问，也不会删除程序解压目录；`v1.0.6` 及以前的脚本不支持此参数。不要用 ZIP 脚本卸载 MSI 安装的版本。
